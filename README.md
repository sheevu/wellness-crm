# PoshanCare - Wellness CRM

A vibrant, India-focused CRM for health & wellness businesses, built with [Hercules](https://hercules.app).

## Features
- Customer profiles with visit tracking (INR pricing, +91 phone format)
- Services catalog
- Kanban-style sales funnel (Lead -> Contacted -> Trial -> Member -> Retained/Churned) with drag-and-drop
- Automated follow-up task creation as customers move through the funnel
- Dashboard with charts for visits, revenue, and funnel breakdown

## Stack
- Vite + React 19 + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Convex (backend & database)
- Hercules Auth (OIDC)

This codebase was exported from the Hercules App Builder.
